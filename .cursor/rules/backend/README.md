# قوانین Backend

قوانین توسعه backend (مثلاً Django، API، دیتابیس) در آینده در این پوشه اضافه خواهند شد.

**ساختار پیشنهادی (بعداً):**
- `backend/core/` — اصول کلی و Git
- `backend/api/` — طراحی REST، status codes، versioning
- `backend/python/` — نوع‌ها، exception، ساختار پروژه
- `backend/testing/` — تست واحد و یکپارچه
- و غیره

Globها به مسیر `backend/**/*.py` (یا مشابه) محدود می‌شوند تا فقط روی فایل‌های backend اعمال شوند.
