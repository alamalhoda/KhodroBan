## 📥 روش 2: دانلود از GitHub (توصیه می‌شود)

### مراحل:

1. به مخزن رسمی Vazirmatn بروید:
   ```
   https://github.com/rastikerdar/vazirmatn
   ```

2. به بخش Releases بروید و آخرین نسخه را دانلود کنید:
   ```
   https://github.com/rastikerdar/vazirmatn/releases
   ```

3. فایل ZIP را دانلود و استخراج کنید

4. از پوشه استخراج شده، فایل‌های `.woff2` را پیدا کنید (معمولاً در مسیر `fonts/woff2/`)

5. فایل‌های زیر را کپی کنید و نام‌گذاری کنید:

   | `Vazirmatn-ExtraLight.woff2` | `Vazirmatn-ExtraLight.woff2` |
   | `Vazirmatn-Light.woff2` | `Vazirmatn-Light.woff2` |
   | `Vazirmatn-Regular.woff2` | `Vazirmatn-Regular.woff2` |

## 📥 روش 3: استفاده از Google Fonts Helper

1. به این آدرس بروید:
   ```
   https://google-webfonts-helper.herokuapp.com/fonts/vazirmatn
   ```

2. وزن‌های مورد نیاز را انتخاب کنید (100 تا 900)

3. فرمت `woff2` را انتخاب کنید

4. فایل‌های CSS و فونت را دانلود کنید

5. فایل‌های `.woff2` را در `frontend-vue/public/fonts/` قرار دهید

## 🔍 استخراج URL مستقیم از Google Fonts

اگر می‌خواهید URL مستقیم فایل‌ها را از Google Fonts بگیرید:

1. به این آدرس بروید:
   ```
   https://fonts.googleapis.com/css2?family=Vazirmatn:wght@100;200;300;400;500;600;700;800;900&display=swap
   ```

2. در صفحه باز شده، URL فایل‌های `.woff2` را پیدا کنید

3. هر URL را در مرورگر باز کنید و فایل را دانلود کنید

4. نام فایل را مطابق جدول بالا تغییر دهید
