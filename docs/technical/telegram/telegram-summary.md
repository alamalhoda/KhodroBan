# خلاصه سیستم نوتیفیکیشن تلگرام

## 🎯 چرا تلگرام؟

| ویژگی | تلگرام | SMS | ایمیل |
|-------|--------|-----|-------|
| هزینه | ✅ رایگان | ❌ پولی | ✅ رایگان |
| سرعت | ⚡ فوری | ⚡ فوری | ⏱️ متوسط |
| تعامل | ✅ دکمه‌ها | ❌ محدود | ✅ خوب |
| فیلترینگ | ✅ بدون مشکل | ✅ بدون مشکل | ✅ بدون مشکل |
| نیاز به استارت | ❌ (اگر شماره ذخیره شده) | ❌ | ❌ |

---

## 🏗️ معماری کلی

```
Python Cron Job (هر روز ۸ صبح)
    ↓
Supabase (خواندن خودروها)
    ↓
محاسبه روزهای مانده
    ↓
اگر در بازه هشدار:
    ↓
خواندن Chat ID از telegram_users
    ↓
ارسال پیام به تلگرام
    ↓
کاربر پیام را دریافت می‌کند
```

## ⚡ ۵ مرحله تا اجرا

### ۱. ساخت ربات (۲ دقیقه)
```
@BotFather → /newbot → دریافت توکن
```

### ۲. اجرای SQL (۱ دقیقه)
```
کپی و اجرای 005_telegram_users.sql
```

### ۳. آماده‌سازی Python (۳ دقیقه)
```
pip install -r telegram_requirements.txt
پر کردن .env
```

### ۴. تست لوکال (۵ دقیقه)
```
python telegram_main.py
python telegram_bot_server.py
curl http://localhost:5000/set_webhook
```

### ۵. استقرار (۵ دقیقه)
```
آپلود به چابکان
تنظیم Cron Job
```

**کل زمان: ۱۶ دقیقه**

## 🎯 نحوه کار کاربر

### برای کاربران:

**فقط ۲ کلیک:**

1. **در وب:** `/profile/telegram` → "اتصال به تلگرام"
2. **در تلگرام:** دکمه "Start"

**تمام!** یادآوری خودکار دریافت می‌کنند.

## ✅ مزایا

1. **کاملاً رایگان** - بدون هزینه پیامک
2. **فوری** - لحظه‌ای ارسال می‌شود
3. **قابل اعتماد** - بدون مشکل فیلترینگ
4. **تعاملی** - دکمه‌های شیشه‌ای
5. **لاگ کامل** - می‌توانید ببینید پیام رسیده یا نه

---

## ⚠️ محدودیت‌ها

1. **نیاز به اینترنت** - کاربر باید اینترنت داشته باشد
2. **محدودیت ۱۰۰۰ پیام/روز** - برای ربات جدید (بعداً برداشته می‌شود)
3. **نیاز به استارت** - یک‌بار اول باید استارت بزند
