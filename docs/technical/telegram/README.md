## 🚀 شروع سریع (۵ دقیقه)

### مرحله ۱: ساخت ربات
در تلگرام به **@BotFather** بروید، `/newbot` بزنید، توکن را کپی کنید.

### مرحله ۲: اجرای SQL
در Supabase SQL Editor جدول `telegram_users` را بسازید (جزئیات در [telegram-quick-start](./telegram-quick-start.md)).

### مرحله ۳–۵
فایل‌های Python، `.env` و تست را آماده کنید — راهنمای کامل در [telegram-quick-start](./telegram-quick-start.md).
