# 📚 مستندات آموزشی

این پوشه شامل راهنماها و آموزش‌های عملی برای استفاده از ابزارها و تکنیک‌های توسعه در پروژه KhodroBan (خودروبان) است.

---

## 📖 فهرست آموزش‌ها

### 🔀 Pull Request

#### [راهنمای کامل Pull Request](./pull-request-guide.md)
راهنمای جامع و کامل برای استفاده از Pull Request در GitHub. شامل:
- چرا از PR استفاده کنیم؟
- Workflow کامل PR
- Best practices
- دستورات مفید Git
- مثال‌های عملی

**زمان مطالعه**: ~20 دقیقه  
**سطح**: مبتدی تا متوسط

#### [راهنمای سریع Pull Request](./pr-quick-start.md)
راهنمای سریع برای شروع استفاده از PR در 5 دقیقه. شامل:
- شروع سریع
- چک‌لیست
- مثال کامل
- سوالات متداول

**زمان مطالعه**: ~5 دقیقه  
**سطح**: مبتدی

## 🎯 نحوه استفاده

### برای شروع سریع
اگر می‌خواهید فوراً شروع کنید، از راهنماهای سریع (Quick Start) استفاده کنید.

### برای یادگیری کامل
اگر می‌خواهید به صورت کامل یاد بگیرید، راهنماهای کامل را مطالعه کنید.

---

## 📝 افزودن آموزش جدید

اگر آموزش جدیدی اضافه می‌کنید:

1. فایل را در این پوشه قرار دهید
2. این README را به‌روزرسانی کنید
3. از فرمت استاندارد استفاده کنید:
   - عنوان واضح
   - فهرست مطالب
   - مثال‌های عملی
   - چک‌لیست (در صورت نیاز)
